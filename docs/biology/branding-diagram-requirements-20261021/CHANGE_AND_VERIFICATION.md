# BioLab branding and drawing requirements — 21 October 2026

The Diagrams tab previously offered one exercise behind an allowlist that required the former water SVG and its unlabelled variant. Restoring the source-PDF water figure made even that exercise unavailable. The course and theme Diagrams tabs now display 25 directly linked activities instead of a generic topic browser. They distinguish explicit guide drawing/construction expectations, diagram skills, and optional recognition practice. The existing labelled/unlabelled engine remains available if its strict original-asset conditions are met; restored source figures use a separate paper-drawing workflow.

Activities cover all four themes, with verified first-assessment-2025 guide codes and printed page numbers. They include water, nucleotides, RNA, DNA, pentose sugars, organelles from micrographs, amino acids/dipeptides, membranes, leaf/stem/root sections, food webs, energy pyramids, carbon cycles, reproductive systems, flowers, pedigrees and Punnett grids. Generic cell drawings and enzyme sketch graphs are labelled useful practice. Required micrograph drawing is distinguished from memorizing a generic cell schematic. Reference percentages in the energy-pyramid model are illustrative; the drawing task calls for actual ecosystem data.

Each activity has a source reference, hide/reveal, an image enlargement dialog, drawing criteria, an attempt self-check and correction notes saved through the existing per-lesson study state. Diagram query links select the requested activity, including multiple activities within a topic. A topic without a separate drawing task links back to the complete checklist. Paper drawings are self-assessed, without automated grading claims.

Existing verified PDF crops are reused wherever possible. Eight additional direct source crops are recorded with PDF page, rectangle, render scale, credit and SHA-256 in SOURCE_REGISTER.json. The source PDFs are excluded from the repository and public assets. All 101 existing original crop hashes and 122 attributed placements are preserved.

Both study-space buttons share a soft green treatment with matching geometry and dark-theme states. The favicon, ICO fallback, Apple touch icon, compact brand marks, BioLab header, default wordmark and contributor certificate wordmark use the existing owner-supplied ibdplabs logo, with the mark cropped directly from that image.

Validation: production TypeScript/Vite build; 40 lesson-package contracts; 553 curriculum statements; site quality; original crop preservation; public output privacy gate; nine drawing tests, including rendering all 25 activity deep links and filtering all four theme catalogues.

Browser verification is not claimed: the managed preview supervisor is unavailable (`sites-previewd mailbox is unavailable at /tmp/sites-previewd/requests`) on both start and status. No replacement preview service was started. The server rendering test covers route-selected content and references but does not replace interactive or responsive browser QA.

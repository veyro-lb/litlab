The current code has 40 Biology lesson packages and 553 registered syllabus understandings across themes A–D. The strict student-facing **Sources** page shows exactly two teaching sources, in the same order for all topics:

1. **Official IB Biology Guide — First Assessment 2025.** Link: https://ibo.org/programmes/diploma-programme/curriculum/sciences/biology/ . The full syllabus Guide is accessed through authorized IB channels; BioLab does not host a mirror.
2. **Biology for the IB Diploma Programme, Third Edition (Hodder, 2023).** ISBN 9781398364240. Link: https://www.hachettelearning.com/biology/biology-for-the-ib-diploma-third-edition . This is an **IB-reviewed** book, not the official syllabus.

Sources are not taken from arbitrary links or reference descriptions in lesson files. References to OpenStax, NCBI, PMC, NASA, etc. are no longer presented as default BioLab teaching references. Historical claim provenance and legal image credits remain in their original lesson and asset records until an eligible editor checks each claim.

### Local or CI reproduction

```bash
npm ci
node scripts/audit-ib-source-policy.mjs --write
node scripts/validate-lessons.mjs
node --test scripts/validate-lesson.test.mjs
node scripts/validate-biology.mjs
node --test scripts/validate-biology.test.mjs
npm run quality
npm run build
```

`--write` generates two local outputs:

- `docs/biology/ib-source-audit/understanding-verification-matrix.csv` — 553 rows with each official ID, SL/HL scope, official Guide page, registered summary, corresponding Hodder chapter/page locator if provided, mapped teaching section, provenance flags, and pending scientific status.
- `docs/biology/ib-source-audit/source-and-editorial-report.md` — source inventory, numerical audit, required re-verification, and remaining review blockers.

The isolated branch workflow also builds and tests a temporary local preview using Playwright and uploads the matrix, report, 12 source/lesson screenshots, and browser findings as a GitHub Actions artifact. That temporary preview does **not** constitute public deployment.

### Blocking tasks before calling BioLab scientifically approved

1. Have an appropriately qualified IB Biology educator and examiner compare each of the 553 sections' **actual scientific explanations, examples, figures, interactions, and marking guidance** against the official Guide and the Hodder chapters. Complete the matrix with actual correction decisions and independent review outcomes.
2. Replace or re-verify teaching assertions currently supported by the 106 legacy outside-policy research references before declaring source-level science compliance. Simply removing the visible citations does not verify the teaching.
3. Verify the biological accuracy, rights and allowed use of every asset and authentic micrograph, keeping original attribution/permission records intact.
4. Determine required IB intellectual-property licenses for third-party digital teaching/curriculum mapping. The Guide's copyright notice indicates that commercial third-party reuse in its ecosystem requires written licensing. Confirm publisher permissions as appropriate; **do not copy textbooks or the Guide into the site**.
5. Conduct the complete editorial, assessment and student learning-effectiveness review before changing lesson status to `approved` or claiming IB endorsement.

Software QA is necessary but is **not** biological certification. BioLab remains independent of the IB unless separately authorized.

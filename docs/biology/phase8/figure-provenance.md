## Authentic microscopy acquisition register (unfulfilled)

- **A2.2.10:** At minimum, collect traceable light micrographs of bacterial, plant and animal cells plus electron micrographs covering each specified structure actually resolved. Proposed sources: university microscopy libraries, NCBI/NIH media and institutional collections with explicitly recorded reuse permissions. Do not use arbitrary rehosted images.
- **A2.2.11:** Acquire electron micrographs clear enough for drawing nucleus, mitochondria, plastid, sap vacuole, Golgi, rough/smooth ER, chromosomes, cell wall, plasma membrane, secretory vesicles and microvilli. Not all structures have to appear in one image.
- **Metadata required for *each* approved image:** direct image URL; creator and institution; specimen and preparation; microscopy modality; calibrated physical scale/scale-bar evidence; original license and terms URL; attribution; permission evidence; exact visible claims; identified limitations; review date and qualified reviewer.
- **Blocker:** No genuine external micrograph is currently bundled or represented as licensed. No original SVG substitutes for actual micrograph analysis. Add authorized files only after human scientific and copyright review.

## Accessibility and mobile QA requirements

- SVG assets use a 640-wide viewBox, high-contrast text and separate recall variants; the shared ScientificFigure component supports zoom and alt text. This is **not** a claim that 320 px mobile rendering has been manually certified.
- Before integration, render all 19 label versions and 19 recall versions at 320 px and desktop sizes, inspect for text clipping, note icon/illustration simplifications, and verify zoom plus keyboard and screen-reader flow.
- Assess any dark-mode styling inherited from shared CSS and preserve visible text at 200% browser zoom. Scientific labels must not depend on color alone.

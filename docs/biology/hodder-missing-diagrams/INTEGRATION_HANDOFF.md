## Safe integration procedure
1. Check the **latest** integration HEAD before adopting any suggested section path; the target was verified on `aab81e48a91607c2bab74192b7447e92046311c8`.
2. For each candidate inspect existing BioLab asset content visually; do not add redundant pictures. Concentrate on mechanism accuracy, stage sequence, causal arrows and understandable IB detail.
3. **Rights gate:** no Hodder figure has documented web redistribution permission. Do **not** import the private PNG crops or source JPEGs into GitHub, `public/`, a deployment or an externally served gallery. Obtain rights for each individual figure or author a scientifically accurate original schematic using independent design, not a tracing.
4. Place only an approved visual **in its numbered teaching section beside the matching explanation**, not in a gallery. Add concise caption, accurate alt and optional enlarged view.
5. Verify SL/HL scope against the 2025 IB Guide and review molecular labels, carbon accounting, directionality, coordinates and accessibility. Complete qualified science review and test desktop/mobile display.
6. Final lesson editing belongs solely to the other integration Work conversation; **this branch modifies no lesson JSON, navigation or public art.**

## Limitations
The entire book was **scanned programmatically**, but this is **not** a manual figure-by-figure scientific approval of all 767 items. Public figure-specific copyright permissions remain **unverified**. The supplemental ZIP has the richer private source/rights ledger and original source-page references.

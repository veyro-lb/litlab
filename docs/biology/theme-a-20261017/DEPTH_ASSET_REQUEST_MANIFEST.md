## Production requirements

All artwork must be produced originally and checked against the IB Guide 2025 understanding ID and the mapped Hodder chapter. Use labels that remain legible on mobile; provide alt text and reference metadata. Include scale bars and instrument methods only when scientifically appropriate. Photomicrographs, databases and conservation imagery must be authentic, traceable, permitted and attributed; illustrative schematics must be marked as models. The biology content owner reviews scientific correctness; the visual team controls visual production and retains its own files.

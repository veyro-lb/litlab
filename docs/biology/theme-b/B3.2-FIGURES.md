# B3.2 provenance and outstanding checks

All three drawings in `public/biology/transport/` are original SVGs created for this package and do not reproduce Hodder or IB figures. `vessel-comparison.svg` is an anatomical schematic (not micrograph); `dicot-stem-root.svg` illustrates representative young-organ geometry (not a calibrated specimen); `heart-circuits.svg` summarizes sequence only and is not a frontal-plane heart anatomy identification figure. Originality is recorded but qualified anatomical inspection is still required.

Textbook: Clegg, Davis, Talbot, Hodder 2023 B3.2 pp.295–325; IB Guide B3.2 printed pp.58–60.
